# Питання для самоконтролю — Лабораторна №4

## Частина 1: JavaScript

1. **Що таке JavaScript і для чого він використовується?** Мова програмування, яка робить веб-сторінки інтерактивними. Виконується в браузері (і на сервері через Node.js). Використовується для обробки подій, зміни вмісту сторінки, запитів до сервера та зберігання даних.
2. **Різниця між JavaScript і ECMAScript.** ECMAScript — стандарт (специфікація ECMA-262), який описує синтаксис і базові можливості мови. JavaScript — реалізація цього стандарту плюс браузерні API (DOM, fetch, localStorage).
3. **Способи підключення JavaScript до HTML.** Вбудований `<script>…</script>`, зовнішній файл `<script src="app.js">`. Зовнішній скрипт зручно підключати в кінці `<body>` або з атрибутом `defer`.
4. **Оголошення змінних.** `var` (застарілий, функційна область видимості), `let` (змінна, блочна область), `const` (константа, блочна область, повторне присвоєння заборонене).
5. **Типи даних.** Примітивні: `string`, `number`, `bigint`, `boolean`, `undefined`, `null`, `symbol`. Об'єкти: `object`, масиви, функції, `Date` тощо.
6. **`null` та `undefined`.** `undefined` означає, що значення не присвоєно. `null` — явна відсутність значення, яку встановлює програміст.
7. **Перевірка типу.** Оператор `typeof` для примітивів, `Array.isArray()` для масивів, `instanceof` для класів, `=== null` для `null`.
8. **Порівняння значень.** Строге порівняння `===` і `!==` без приведення типів. Нестрогий `==` приводить типи, тому його уникають. Для `NaN` використовують `Number.isNaN()` або `Object.is()`.
9. **Тернарний оператор `?`.** `умова ? значення_якщо_true : значення_якщо_false`. Повертає одне з двох значень, наприклад `const theme = hours >= 7 ? 'light' : 'dark';`.
10. **Умовне виконання.** Конструкції `if`, `else if`, `else` і `switch`.
11. **Цикли.** `for` (відома кількість ітерацій), `while` і `do…while` (перевірка умови перед або після тіла), `for…of` (значення ітерованого об'єкта), `for…in` (ключі об'єкта). Різняться умовою перевірки та способом обходу.
12. **`break` і `continue`.** `break` повністю завершує цикл або `switch`. `continue` пропускає поточну ітерацію і переходить до наступної.

## Частина 2: React

1. **Навіщо `useEffect` для отримання даних.** Ефект виконує побічні дії (запити, таймери, підписки) після рендеру. Це не дає їм блокувати рендер і не дає компоненту зациклитися.
2. **Вплив `[]` на виконання.** Порожній масив означає, що ефект виконається один раз після першого монтування. Без масиву ефект запускається після кожного рендеру. Зі змінними в масиві — при їх зміні. Функція очищення виконується при розмонтуванні.
3. **Чому `useState`, а не звичайна змінна.** Звичайна змінна скидається при кожному рендері і її зміна не перемальовує компонент. `useState` зберігає значення між рендерами і запускає новий рендер після `setState`.
4. **Як не відкривати модальне вікно повторно.** Зберегти прапорець після закриття (у проєкті — `localStorage` з ключем `contactFormDismissed`) і перевіряти його перед запуском таймера.
5. **Пряме маніпулювання DOM і декларативний React.** `document.getElementById` змінює DOM напряму, крок за кроком (імперативно). React описує бажаний стан інтерфейсу через дані, а сам оновлює DOM.
